# 游戏配音工作台

给独立游戏开发者使用的本地配音工具：先选角色声音，再写台词、调整表达，最后导出到游戏或视频中。

基于 [Voicebox](https://github.com/jamiepine/voicebox) 进行中文界面和游戏台词流程适配，普通配音使用 Qwen3-TTS，可选情绪配音使用 IndexTTS 2.5。**主程序开源；模型与部分第三方组件适用各自条款，不能统一视为 MIT。**

## 下载与开始

**[下载 Windows 测试版](https://github.com/JamStrak/game-voice-workbench/releases/tag/v0.1.0-beta.1)**，选择附件 `game-voice-workbench-0.1.0-beta.1-windows-x64.zip`。

1. 完整解压到自己的文件夹，例如 `D:\GameVoice`。不要在 ZIP 内直接运行，也不要放进 Windows 系统目录。
2. 第一次双击 **安装配音工作台.vbs**，在安装窗口中选择安装并查看进度。安装器会准备独立 Python、依赖、FFmpeg 和模型；不需要预装 Git、Node、Python 或 CUDA Toolkit。
3. 安装完成后双击 **打开配音工作台.vbs**，浏览器打开本地工具。
4. 在“声音”里试听并选用角色，返回“生成”输入短句；多角色批量台词使用“角色台词”。
5. 用完后双击 **关闭配音工作台.vbs** 停止服务。仅关闭网页不会停止后台任务。

首次安装需要网络、磁盘空间与等待；这是自动安装版，不是包含全部大模型的离线整合包。安装中断后可重新运行。GitHub 的“Code → Download ZIP”也包含预编译页面和安装入口，但日常使用建议下载 Release 中固定版本的附件。

只想先试声音时，在安装窗口选择“仅试听”：首次使用 CPU 依赖、不下载语音模型。以后需要生成时，先关闭工具，再运行安装器选择“基础配音”，自动补齐 GPU 依赖与模型。

## 可以做什么

- 9 种角色音色、36 段真实中文试听，每种都有自然、开心、愤怒、悲伤短句。
- 保存项目角色，为角色设置默认表达、语速与音高。
- 输入普通旁白或角色台词，生成、试听、保留不同版本并导出 WAV。
- 批量台词编号、分配角色、单条重做、选择满意版本、按编号导出 ZIP。
- 使用本人或已授权的参考录音制作声音档案。
- 安装可选情绪引擎后，可手动指定情绪，也可分析文本并采用建议。

声音库试听直接播放现成文件，不需要加载语音模型。**生成新语音需要计算时间，不是实时配音。** 情绪和克隆效果请按实际听感判断，不能保证每句都准确或与参考完全一致。

## 系统要求

| 项目 | 首发支持范围 |
| --- | --- |
| 系统 | Windows 10 / 11，64 位 x86 |
| 生成显卡 | NVIDIA，推荐至少 6 GB 显存，并安装可用驱动 |
| 内存 | 普通配音建议 16 GB；情绪配音建议 32 GB，启动合成时需至少 8 GB 空闲内存、4 GB 空闲显存 |
| 磁盘 | 基础配音首次安装建议至少 20 GB 可用空间；情绪引擎安装建议至少 40 GB。基础模型文件合计约 5.01 GB，另有环境、下载缓存及成品 |
| 网络 | 首次安装需下载运行环境与模型；准备完成后推理使用本地模型 |
| 其他平台 | 本发行版未验证 macOS、Linux、AMD 或纯 CPU 合成 |

实测开发机是 RTX 3060 Laptop 6 GB、16 GB 内存。声音试听与生成对硬件的要求不同；低配置机器的实际体验尚需更多反馈。

## 情绪引擎

普通安装提供 Qwen 自然配音与克隆。需要生成开心、愤怒、悲伤等表达时，双击 **安装情绪引擎.vbs**，阅读对应模型条款并自行选择是否接受，安装器会准备独立环境与固定版本的 IndexTTS 源码和模型。36 段内置试听随包提供，试听不要求安装该引擎。

IndexTTS 的 bilibili Model Use License 并非 MIT/Apache。中文条款优先，含商业使用收入门槛、用途及再分发要求；**随包的 27 段情绪试听也适用相关条款**，不因没有安装模型而改为 MIT。使用或再分发前请阅读 [第三方说明](THIRD_PARTY_NOTICES.md) 与所附原文。不要把模型条款、声音授权与主程序许可证混为一谈。

## 数据与常见问题

录音、角色、历史和成品留在自己的 `data/`；不要把整个目录发到公开 Issue。备份时保存 `data/` 和 `local_config.json`。升级前先关闭程序、备份数据，再按新版本说明操作，不要直接覆盖正在工作的目录。

- **安装失败**：查看安装窗口给出的错误及 `logs/` 日志；重新运行安装器。网络代理、模型源连通性和剩余磁盘空间都可能影响首次准备。
- **提示 DLL load failed / WinError 126、127、1114**：可能缺少系统运行库，可安装[微软 Visual C++ x64 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe)后重试。安装器不会自动更改显卡驱动或系统运行库。
- **页面打不开**：重新双击打开入口。默认地址为 `http://127.0.0.1:23164`；端口被其他程序占用时自动回退到 23165–23183，以启动器打开的地址为准。
- **试听正常，生成不成功**：确认模型安装完成、显卡驱动可用，并查看页面的具体错误。情绪引擎需要另外安装。
- **切换试听后出现旧界面**：刷新已打开的页面，使用当前发行包启动的地址。
- **没有声音或出现卡顿**：在 Issue 中描述具体音色、情绪、操作顺序及机器配置，附经过检查的错误文字即可。
