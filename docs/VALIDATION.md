# 发行验证

此文件记录 0.1.0-beta.1 的实际验证范围。首发面向 Windows 10/11 x64 和 NVIDIA 显卡；不把单机检查视为所有电脑兼容性保证。

## 已有功能基础

此前已在 RTX 3060 Laptop 6 GB / 16 GB 内存机器完成中文配音、参考样音克隆、批量角色台词、情绪生成、取消释放、版本保留与导出验证。声音库 9 种音色、36 段 WAV 的完整性和哈希均通过。

播放优化版本的浏览器连续切换、关闭重开、暂停恢复、定位和循环播放检查通过。本次发行通过 123 项后端测试、68 项前端测试、App / Web 类型检查与生产构建。

## 首次安装与发行验证

2026-09-26 在独立干净目录完成 Windows PowerShell 5.1「仅试听」安装：自动下载独立 Python 3.12.8、CPU PyTorch / torchaudio 2.6.0、锁定的应用依赖及 FFmpeg 9.0.2；没有复用开发环境的 Python，也没有加载语音模型。

- 安装完成后，首页、声音、角色台词、模型和设置入口均返回生产页面；模型状态正确显示尚未下载。
- 启动器重复打开复用同一进程；验证结束后仅关闭本次启动的服务。
- 36 段内置 WAV 的 HTTP 读取和 SHA256 全部通过，缓存 304、Range 分段读取、批量状态接口及 24 次混合并发请求通过。
- 本机回环 HTTP 完整短音频请求中位约 19.29 毫秒，混合请求中位约 16.95 毫秒、最大约 33.12 毫秒。这是该次环境的测量，不代表其他电脑或模型生成速度。
- 安装期间实际遇到过下载源 TLS 中断，重新运行后利用缓存完成；修复了 PowerShell 5.1 原生命令引号导致导入检查误报的问题。
- 发行文件使用白名单导出与 SHA256 清单，包含预编译界面和试听；不包含开发者配置、录音、项目历史、数据库、模型权重或运行环境。

同日 GitHub 托管的独立 Windows 环境也完成了全新 CPU 试听安装、启动复用、36 段试听校验和关闭验证。仓库同时提供 Windows 源码检查和干净试听安装的 GitHub Actions；每次运行状态以仓库 Actions 页面为准，该自动流程不加载模型。

## 未覆盖范围

- 未在多台不同显卡、不同驱动和不同 Windows 语言环境的实体电脑实测。
- 按本轮验证范围，未在新安装环境运行 GPU 配音或可选情绪模型；已有生成结果来自此前开发环境，不能当作新环境生成验收。
- 未验证 macOS、Linux、AMD 或纯 CPU 合成；不要按这些平台宣传本发行包。
- 真人听感、克隆相似度与情绪准确性取决于台词、参考录音和模型，欢迎实际试听反馈。
- 首次下载速度受 GitHub、软件源和模型源连通性影响，不保证固定安装时长。
